==================================================
MindBreakout - Level Format Guide
==================================================

This file explains every option available in a level file.

Levels are JSON files stored inside the "levels" folder.

Example:

levels/
├─ default_level.json
├─ level1.json
├─ boss_level.json

The game automatically reads these files through the Level Select menu.

If a value is missing from your level file, the game will automatically use a default value.


==================================================
BASIC LEVEL STRUCTURE
==================================================

Example:

{
    "Mode": "A",
    "Lives": 3,
    "Difficulty": 5
}

All other settings are optional.


==================================================
MODES
==================================================

The game currently supports two different gameplay modes.

--------------------------------------------------
Mode A
--------------------------------------------------

Traditional Breakout gameplay.

The game creates a grid of blocks at the top of the screen.

The player must destroy all blocks to clear the level.

Blocks can use:
- Solid colors
- Custom sprites

Example:

"Mode": "A"


--------------------------------------------------
Mode B
--------------------------------------------------

Reveal Mode.

Instead of generating blocks, the game loads an
Overground Sprite.

Every visible pixel of the overground image acts as a
destructible block.

When the ball touches a visible pixel:

- The pixel is removed.
- The image becomes transparent in that area.

This allows creators to make:

- Boss fights
- Hidden images
- Reveal puzzles
- Story scenes
- Large destructible artwork

Example:

"Mode": "B"

Required:

"Overground_Sprite": "overlay.png"


==================================================
LIVES
==================================================

Controls how many balls the player receives.

Example:

"Lives": 5

Default:

3


==================================================
DIFFICULTY
==================================================

Controls how quickly the ball gains speed.

Range:

0 - 10

0
=
Ball never accelerates.

10
=
Ball accelerates very quickly.

Example:

"Difficulty": 7

Default:

5


==================================================
BALL_STARTING_SPEED
==================================================

Controls how fast the ball launches.

Range:

0.1 - 1.0

Example:

"Ball_Starting_Speed": 0.75

Default:

0.5


==================================================
BACKGROUND_COLOR
==================================================

Used when no background image is specified.

Accepts a list of HEX colors.

Example:

"Background_Color": [
    "#000000"
]

Default:

["#000000"]


==================================================
BACKGROUND_SPRITE
==================================================

Loads a background image.

File location:

assets/backgrounds/

Example:

"Background_Sprite": "forest.png"

The image is automatically resized to fit the game window.

If empty, Background_Color is used.

Default:

""


==================================================
BLOCK_COLORS
==================================================

Used in Mode A.

If no block sprites are supplied, blocks will use these colors.

Example:

"Block_Colors": [
    "#ff6666",
    "#ffaa66",
    "#ffff66"
]

Default:

[
    "#ff6666",
    "#ffaa66",
    "#ffff66"
]


==================================================
BLOCK_SPRITES
==================================================

Used in Mode A.

Loads custom block graphics.

File location:

assets/blocks/

Example:

"Block_Sprites": [
    "brick1.png",
    "brick2.png",
    "brick3.png"
]

The game randomly chooses one sprite for each block.

Sprite Rules:

- Maximum display size is 100x100.
- Large sprites are scaled down.
- Smaller sprites are not scaled up.
- Transparent pixels do not count for collision.
- Visible pixels are used for collision.

If empty, Block_Colors are used instead.

Default:

[]


==================================================
PADDLE_SPRITE
==================================================

Loads a custom paddle image.

File location:

assets/paddles/

Example:

"Paddle_Sprite": "paddle.png"

The paddle image is scaled to fit the paddle.

If empty, the default paddle is used.

Default:

""


==================================================
OVERGROUND_SPRITE
==================================================

Used only in Mode B.

File location:

assets/overgrounds/

Example:

"Overground_Sprite": "boss_mask.png"

Rules:

- Automatically scaled to the game window.
- Visible pixels become destructible.
- Transparent pixels do not collide.

Useful for:

- Boss fights
- Reveals
- Hidden artwork
- Interactive images

Default:

""


==================================================
SPIRAL_SPEED
==================================================

Controls spiral rotation speed.

Example:

"Spiral_Speed": 0.25

0.0
=
No movement

Higher values
=
Faster rotation

Default:

0.25


==================================================
SPIRAL_THICKNESS
==================================================

Controls spiral line thickness.

Example:

"Spiral_Thickness": 4

Thin spiral:

1

Heavy spiral:

6

Default:

2


==================================================
SPIRAL_COLORS
==================================================

Colors used by the spiral.

Example:

"Spiral_Colors": [
    "#ffffff",
    "#00ffff",
    "#ff00ff"
]

At least two colors are recommended.

Default:

[
    "#ffffff",
    "#999999"
]


==================================================
PHRASES
==================================================

List of phrases displayed during gameplay.

Example:

"Phrases": [
    "FOCUS",
    "KEEP PLAYING",
    "WATCH THE BALL"
]

Leave empty to disable phrases.

Default:

[]


==================================================
PHRASE_APPEAR_SPEED
==================================================

Time in seconds required for phrases to become fully visible.

Example:

"Phrase_Appear_Speed": 15

Default:

20.0


==================================================
PHRASE_SCROLL_SPEED
==================================================

Controls phrase movement speed.

Example:

"Phrase_Scroll_Speed": 60

Higher values move text faster.

Default:

40


==================================================
PHRASE_MAX_COUNT
==================================================

Maximum number of visible phrases.

Example:

"Phrase_Max_Count": 12

Higher values create a denser screen.

Default:

6


==================================================
PHRASE_COLOR
==================================================

Color used for phrase rendering.

Example:

"Phrase_Color": "#00ffff"

Default:

"#ffffff"
