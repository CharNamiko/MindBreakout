MindBreak out is a simple python game built for fun from a random idea of:
What if Breakout, but hypnotic?

...and thus this game concept was born.

Allows for the use of custom levels. And that's about it.

Currently there is a txt file on how to make a level to load in. And a test level I use as a base.
You can edit the lives, speed of the ball, colours, the spiral, the phrases that appear, etc.

Controls are simple:
Arrow Keys - Move/Change Selection
Space - Launches Ball/Pick Selection
